# 우리 가족 기록장

로나 · 태리 · 엄마 · 아빠를 위한 가족 기록장 웹앱입니다.

- 앱 주소: https://tak-1234.github.io/family-log/
- 아이폰/아이패드 사파리에서 열고 **공유 → 홈 화면에 추가** 하면 앱처럼 쓸 수 있어요.
- 기록은 **가족 공용 저장소(Supabase)** 와 각 기기 브라우저(localStorage)에 함께 저장됩니다.
  - 기기별 기록은 즉시 화면에 반영되고, 가족 공용 저장소를 통해 다른 기기(엄마 폰 · 아빠 폰 · 아이패드)와 실시간으로 맞춰집니다.
  - 인터넷이 끊겨도 이 기기에는 계속 저장되고, 다시 연결되면 자동으로 맞춰집니다.
  - 채팅 탭 위쪽 띠에서 연결 상태를 확인할 수 있어요. (`🟢 실시간 가족 연동 중` / `연결 대기 중`)

## 구성

- 단일 파일 `index.html` (빌드 없음, 외부 의존성: Open-Meteo 날씨 API, @supabase/supabase-js@2 CDN)
- 가족 공용 저장소
  - `public.family_state` — `id = 'tak-family-main'` 1행에 가족 기록 전체(jsonb)
  - `public.family_messages` — 가족 채팅 메시지
- 앱이 처음 열릴 때 `family_state` 행이 없으면 지금 화면의 기록을 그대로 올려서 시작합니다.
